# Project Mapping: Backend (card-api)

This directory is the **Backend** service (`card-workspace/card-api`).

- **Project Location**: `card-workspace/card-api` (or `./` within this project root)
- **Tech Stack**: NestJS 11, Prisma ORM 6, PostgreSQL, JWT Authentication, TypeScript
- When the user mentions "Backend", operations and commands belong to this folder.
- When the user mentions "Mobile", refer to the companion mobile project at `../card-mobile/` (under `card-workspace/card-mobile`).
- **Portability Rule**: Never assume hardcoded absolute user machine paths. Always resolve paths relative to `card-workspace`.
